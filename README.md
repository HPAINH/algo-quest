# Algo Quest

Тренажёр серии Quest по методичке «Алгоритмы для собеседования»: 40 глав в 9 частях (урок → интерактив → задания → тест): от сложности и хешей до графов, ДП, битов, строк и продвинутых тем (LRU, quickselect, Фенвик, Манакер, мосты). После всех глав открывается алгособес (23 задачи) с таймером и запуском Python в браузере (Pyodide).

## Публикация на GitHub Pages

1. Создай репозиторий `algo-quest` в аккаунте HPAINH.
2. Загрузи в корень `index.html`, папку `py/` и (по желанию) `src/`.
3. Settings → Pages → Source: ветка `main`, папка `/ (root)`.
4. Через минуту сайт будет на `https://hpainh.github.io/algo-quest/`.

Сайт нужно открывать через веб-сервер (GitHub Pages или `python -m http.server`), а не двойным кликом по файлу: Python загружается из папки `py/`.

## Пересборка после изменения контента

```
cd src
python3 lessons.py      # главы 1–11: method.md → lessons.json
# главы 12–40 описаны прямо в new_a.py … new_f.py
python3 validate.py     # проверка: эталоны проходят тесты, ошибочные версии падают
PYODIDE_DIR=путь/к/pyodide-0.26.4 python3 build.py   # сборка в dist/ (файлы из npm-пакета pyodide@0.26.4)
```
