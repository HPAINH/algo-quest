## 01 · Проблема

> Алгоритмическая секция — главный фильтр на собеседованиях в Яндекс, Т-Банк, Ozon, VK.

- 📚 Теория разбросана по книгам, статьям и видео, нет единого маршрута.
- 🧱 LeetCode даёт задачи, но **не учит**: непонятно, с чего начать и почему решение именно такое.
- 🎭 На собесе оценивают не только код, но и **ход мысли**: уточнения, брутфорс, сложность, проверку. Это нигде не тренируют.

---

## 02 · Решение

**Algo Quest** — путь в два этапа:

| Этап 1 · Изучение | Этап 2 · Алгособес |
| :--- | :--- |
| 40 глав от основ до продвинутых тем | Открывается, только когда пройдены все главы |
| Урок → визуализатор → задания → тест | 2 задачи, таймер 45 минут |
| Python запускается прямо в браузере | Шаги как на реальном интервью |
| Подсказки в 5 уровнях | Отчёт и вердикт **hire / no hire** |

---

## 03 · Как устроена глава

```
📘 Урок         →   🎞 Визуализатор   →   🧩 Задания        →   ✅ Тест
идея, шаблон,       алгоритм по шагам,     8 типов заданий,       5 вопросов,
сложность,          подсветка кода,        код с тестами          нужно 4 из 5
ошибки              свои данные            и проверкой скорости
```

## 05 · Почему это работает

- 🔍 **Сначала понимание, потом практика.** Каждый алгоритм видно в движении: можно пройти по шагам на своих данных.
- 🐍 **Настоящий код, а не тесты с вариантами.** Решение проверяется открытыми и скрытыми тестами и тестом на скорость: O(n²) там, где нужно O(n), не пройдёт.
- 🪜 **Подсказки дозированы.** Пять уровней: от наводящего вопроса до почти готового решения. Звёзды за главу зависят от того, сколько подсказок понадобилось.
- 🎯 **Собес как настоящий.** Уточнить условие → назвать брутфорс → выбрать технику → написать код → проверить → получить разбор.

## 06 · Отчёт после собеса

| Критерий | Что оценивается |
| :--- | :--- |
| **Решение задачи** | решены ли задачи, сколько подсказок понадобилось, найдена ли техника с первой попытки |
| **Коммуникация** | ключевые уточняющие вопросы, свой пример, брутфорс до оптимизации |
| **Код** | прохождение тестов с первой отправки, тест на скорость |
| **Тестирование** | запуск на примерах до отправки, верно названная итоговая сложность |

Итог — вердикт **hire / no hire** и конкретные точки роста.

## 08 · Технологии

| | |
| :--- | :--- |
| **Фронтенд** | чистый JavaScript, один HTML-файл, светлая и тёмная тема, адаптив |
| **Python в браузере** | Pyodide 0.26.4 в Web Worker, таймаут и защита от бесконечного цикла |
